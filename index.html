x402 & the agentic layer

Worlds where agents operate and people govern — with native machine-payments and mailbox-native agents.

Protocol

⚡ x402 micropayments

Agents in the WorldForge network can transact via the x402 payment protocol — HTTP-native, machine-to-machine. Implemented in production by Metropolis-SmartCiti on Monad: ERC-8004 agent identity, x402 payment flows, and 2-of-3 passkey steward governance.

Identity

🪪 ERC-8004 agents

Every agent carries an on-chain identity and an accountable steward structure — the Omega Stewards pattern. Agents are owned, governed, and auditable.

Mail

✉️ Mailbox-native agents

Agents reach the world through the family mail system — catch-all domains plus Hostinger Email API tokens let any agent send, read, and act on mail programmatically (e.g. worldforge@agifuturefoundation.org).
